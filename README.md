# 🎯 AI Job Hunter

A free, CV-driven job search agent. Upload your CV (any background — tech, medical, sales, data...), and it searches fresh LinkedIn jobs via Apify, ATS-scores every result against YOUR CV, and shows the best matches with hyperlinks and full analytics.

```
Upload CV → auto skill detection → Apify (LinkedIn) scrape → ATS scoring → ranked results + Full Analysis
```

## Features

- **CV-driven search** — upload a PDF/TXT CV and it auto-extracts your skills; if you don't type keywords, it searches with your CV's own skills.
- **Universal skill coverage** — the curated skill database covers every field (AI/ML, web, data, DevOps, design, healthcare, sales, finance, HR, education, hospitality...) so any CV finds relevant jobs.
- **ATS scoring on every job** — two layers:
  - Quick TF-IDF keyword score (0-100) on all results, used for sorting/filtering; a relevance gate drops jobs that share none of your skills.
  - **Full Analysis** (per job) — a deterministic 8-category engine (Required Skills, Experience, Role Alignment, Preferred Skills, Education, Keyword Relevance, Certifications, ATS Readability) with matched/missing skills, hard blockers, and recommendations.
- **No hallucinations** — the summary and scores are computed from the engine, not generated by the LLM.
- **One entry point** — upload CV, type in chat, done.
- **Sidebar filters** (all optional) — query, location, job type (Remote/Hybrid/Onsite), freshness, max results.
- **Graceful fallback** — if the LLM fails, parsers fall back to regex/heuristic extraction so scoring still works.

## Setup

```bash
cd "D:\AI JOB SEARCH"
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt

copy .env.example .env     # then fill in APIFY_API_KEY and GROQ_API_KEY
```

Get keys (both have free tiers):
- Apify: https://console.apify.com/settings/integrations
- Groq: https://console.groq.com/keys

## Run

```bash
streamlit run app.py
```

1. Upload your CV in the sidebar.
2. Type anything in the chat (e.g. "find me jobs" or "machine learning jobs in London").
3. Results appear as cards: blue hyperlink title, ATS score + color, company/location/salary, matched & missing keywords.
4. Click **📋 Full Analysis** on any job for the full breakdown inline.

## Cost & keys

- **Apify actor:** `curious_coder/linkedin-jobs-scraper` (LinkedIn) — the most reliable job scraper on Apify. Pay-per-event, **$1 per 1,000 jobs**. The free plan gives **$5/month**, so ~**5,000 jobs/month free**.
- **Groq (`allam-2-7b`)**: free tier, fast LLM inference for resume/JD parsing.
- Sessions always scrape fresh from LinkedIn — no stale DB.

## Project layout

```
app.py                    Streamlit UI (sidebar filters, chat, job cards, Full Analysis)
config.py                 .env settings (GROQ_MODEL, APIFY_ACTOR, keys)
run_scrape.py             Standalone CLI job scraper
src/
  agent.py                Orchestrates: question -> build query -> Apify -> ATS score -> answer
  scraper.py              Apify actor client (run_job_search)
  normalize.py            Raw Apify item -> schema, dedup by URL
  ats_scorer.py           Quick TF-IDF ATS score + relevance gate + skill database
  llm.py                  Groq chat client (retry + thinking-block stripping), search-param extraction
  resume_matcher.py       PDF/TXT resume text extraction + skill detection
  db.py                   Chat history (SQLite)
  embeddings.py           warmup (reserved)
  ats/                    Full analysis engine (deep scoring)
    scoring_engine.py     score_resume_vs_jd — deterministic 8-category scoring
    resume_parser.py      LLM resume -> structured data (lean schema)
    job_parser.py         LLM JD -> structured requirements
    semantic_matcher.py   Per-skill evidence classification (LLM) + fallback
    recommendation_engine.py  Suggestions + hard blockers
    ats_readability.py    Formatting/readability check
    llm_client.py         Groq JSON client (retry, JSON coercion, thinking stripping)
    models.py             Pydantic schemas (ResumeData, JobData, ScoringResult...)
```

## Configuration (`.env`)

```ini
APIFY_API_KEY=...
GROQ_API_KEY=...
APIFY_ACTOR=curious_coder/linkedin-jobs-scraper
GROQ_MODEL=allam-2-7b
```

> Note: `allam-2-7b` has a 4096-token window. The parsers use lean JSON schemas and compacted input so the LLM output fits — this keeps parsing reliable.

## Tips

- Use sidebar filters (location, job type, freshness) to narrow results.
- To score a specific job description, paste the JD in chat with a word like "score"/"ATS"/"match".
- If a scrape returns nothing, remove the location filter — LinkedIn results vary by region.
